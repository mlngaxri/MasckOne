# Start Here — MASCK ONE Core Sketch

If you are about to work on Masck One, read in this order:

1. `CORE_SKETCH_ONE_PAGE.md`
2. `CORE_SKETCH_V1.md`
3. `CORE_SKETCH_STATUS_BOARD.md`
4. `CORE_SKETCH_EXECUTION_BACKLOG.md`
5. `CORE_SKETCH_REPO_MAPPING.md`
6. the relevant subsystem engineering docs and live authority.

For broad autonomous work, pick the highest-priority backlog item with satisfied dependencies and continue its existing owner lineage.

For a proposed concept change, read `CORE_SKETCH_CHANGE_CONTROL.md` and write the decision to `CORE_SKETCH_DECISION_LOG.md` if accepted.

For research history, use `research/CORE_SKETCH_DEEP_RESEARCH_2026-09-10.md`; archived ideas are not selected simply because they are written there.

Live engineering authority and accepted evidence always outrank product-concept documents on claims of what physically exists or works.
