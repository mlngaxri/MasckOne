# MASCK ONE Core Sketch — One-Page Product Test

MASCK ONE is a **complete automated facial-skincare system**.

A correctly evolving product should still satisfy this story:

> The dock stores the user’s own skincare and quietly prepares the next scheduled routine. The user lifts one calm, premium facial object, places it, lets it self-align and presses one precise physical control. Masck cleans, rinses/recovers, performs the selected treatment stages, applies the user’s leave-on products and, when validated, facial sunscreen. It then enters a non-wiping release state. The user removes it and does not need to touch the face again to finish that facial skincare routine. The product is returned to the dock with one soft positive settlement; service, charging and next-routine preparation happen largely out of sight.

The product should look and feel like premium personal care, not VR, PPE, robotics, gaming hardware or a floppy LED mask.

The outside is calm: Mineral Ivory, controlled continuous facial volume, large clean eye openings, hidden sophistication, sparse branding, quiet Opal status language.

The inside may be exceptionally complex, but the consumer should mainly experience:

**GRAB → PLACE → SELF-ALIGN → START → DO SOMETHING ELSE → RELEASE → REMOVE → RETURN**

The platform adapts to supported third-party skincare through exact product identity, versioned application profiles, physical characterization and deterministic safety bounds. AI helps identify and organize; it never becomes the safety authority.

Normal configured operation works without phone, cloud or internet.

The following are not the product: proprietary skincare lock-in, makeup automation in V1, RGB status bars, a talking mask, beauty scores, VR-style headgear, fake vents, visible plumbing, constant buzzing/beeping, uncontrolled heat or competitor-feature accumulation.

If a future design no longer satisfies this page, it requires an explicit Core Sketch change rather than being treated as routine refinement.
