# MASCK ONE Core Sketch Review Order

For a full product review, evaluate in this sequence:

1. Complete-routine promise and user value.
2. Reduced physical feasibility of cleanse/rinse/leave-on/release.
3. Protected anatomy, airway and emergency removal.
4. Mass/CG/fit/vision.
5. Product compatibility and contamination boundaries.
6. Dock/session-dose ownership model.
7. Leave-on application quality.
8. Hygiene/service.
9. HMI/tactile/acoustic quality.
10. Optional treatment modalities: massage, WARM/COOL, optical.
11. SPF as its own claims-quality application problem.
12. App/scheduling/product database/offline/privacy/accessibility.
13. Integrated full-face alpha.
14. Long-term ownership/reliability/material ageing.
15. Demand/economics.
16. Production-intent closure.

Do not reverse this order by polishing optional optical/AI features while the complete-routine sequence remains unproven.
