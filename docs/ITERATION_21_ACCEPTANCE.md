# Iteration 21 acceptance: cleanser storage, refill, compatibility, and purge

Iteration 21 defines a dedicated cleanser storage path with exact `CLEANSER` fluid identity, stable refill/outlet/purge ports, `WET_REMOVABLE` service classification, backflow-isolation intent, and explicit purge and cleaning boundaries.

The 0.60 mL nominal CLEAN-cycle dose is consumed directly from machine authority with its `VALIDATION_GATED` status preserved. Storage capacity, dead volume, and purge volume remain unresolved because no controlled internal geometry justifies those values.

Compatibility evidence must identify the cleanser formulation and wetted material, use a controlled evidence kind, and carry an immutable artifact SHA-256. Attaching evidence moves the digital state only to engineering review required. It cannot automatically establish material compatibility or physical validation.

This iteration does not demonstrate dosing accuracy, chemical compatibility, backflow prevention, leakage, cleanability, or hygiene performance.
