# Iteration 21 acceptance: cleanser storage, refill and purge

Iteration 21 creates a dedicated cleanser storage path with explicit CLEANSER fluid identity, stable refill/outlet/purge ports, WET_REMOVABLE service classification, backflow-isolation intent, purge/cleaning architecture and controlled compatibility-evidence metadata.

The nominal 0.60 mL per CLEAN cycle is consumed directly from authority with its validation-gated status preserved. Storage capacity, dead volume and purge volume are intentionally unresolved because controlled 3D geometry does not yet justify them.

Chemical compatibility remains blocked until a selected cleanser formulation, selected wetted materials and controlled supplier/coupon/component evidence exist. Attaching evidence records changes the state only to engineering review required, never automatically to a final compatibility claim.

This release does not demonstrate dosing accuracy, chemical compatibility, backflow prevention, leak performance, cleanability or hygiene performance.
