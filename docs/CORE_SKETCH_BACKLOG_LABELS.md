# MASCK ONE Backlog Label Semantics

Use these labels in issue/PR titles, bodies or future tracking automation when useful.

- `core-sketch/P0` — existential or identity-critical.
- `core-sketch/P1` — required for coherent V1.
- `core-sketch/P2` — important supporting quality/capability.
- `core-sketch/P3` — later/future.
- `core-sketch/locked` — product intent should not change casually.
- `core-sketch/prove` — physical/empirical evidence required.
- `core-sketch/explore` — bounded alternatives allowed.
- `core-sketch/integrate` — existing owner work must be reconciled into whole product.
- `core-sketch/blocked` — dependency prevents closure.
- `core-sketch/rejected` — do not revive without new evidence.

These are semantic conventions; this document does not require GitHub labels to exist.
