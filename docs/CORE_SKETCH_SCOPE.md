# MASCK ONE Core Sketch Scope

The Core Sketch suite covers product purpose, features, user journey, routine logic, product compatibility, dock/wearable division, industrial-design language, CMF, fit/sizing intent, sensory behavior, optical/thermal treatment experience, hygiene/service, failure states, accessibility, privacy, offline operation, ownership and validation priorities.

It intentionally does **not** freeze detailed mechanisms, pump topology, actuator internals, bearings, fasteners, PCB routing, firmware implementation, production tooling or supplier selection. Those are refined later by the canonical subsystem owners under the Core Sketch requirements.
