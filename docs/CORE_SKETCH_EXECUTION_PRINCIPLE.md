# MASCK ONE Execution Principle

Every future Masck task should answer four questions before implementation:

1. **Which Core Sketch backlog item does this close?**
2. **Which existing owner lineage owns the truth?**
3. **What evidence can this task actually produce?**
4. **What remains physically unproven afterward?**

If those answers are unclear, the task should be triaged before more architecture is created.
