# MASCK ONE End State

The intended end state is simple to describe even if difficult to engineer:

The user’s skincare is loaded in the dock. Their schedule is already known. Masck is prepared before they reach for it. They place one calm, balanced object on the face, press one precise control and continue with their life. The system cleans, rinses, performs the selected treatments, applies the selected leave-on products and facial SPF where validated, then moves to a non-wiping release state. They remove it with no required finishing touch, return it to the dock, and the system quietly prepares for next time.

All product complexity exists to make that sequence feel inevitable.
