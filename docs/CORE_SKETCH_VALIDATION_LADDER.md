# MASCK ONE Core Sketch Validation Ladder

Status: **evidence progression for concept promotion**

Masck One should earn the right to continue by climbing this ladder. A later rung does not replace an earlier one.

## Gate 1 — Concept coherence

Pass when:

- the product is still recognizably the Core Sketch v1;
- complete-routine hierarchy is intact;
- no major feature depends on hidden contradictory assumptions;
- rejected feature creep has not returned.

Evidence: DOC.

## Gate 2 — Reduced-zone physical feasibility

Pass when a reduced cheek/full-routine rig demonstrates:

- cleansing;
- rinse/recovery;
- transition to leave-on state;
- representative serum;
- representative moisturizer;
- non-wiping release;
- tolerable contamination/leakage behavior.

Evidence: BENCH.

## Gate 3 — Product-family feasibility

Pass when representative thin, medium and thick skincare families can be identified, characterized and applied within a bounded envelope without requiring a custom mechanism for every SKU.

Evidence: BENCH + data model.

## Gate 4 — Whole-face digital integration

Pass when the canonical assembly integrates current owner subsystems, full-routine session quantities and protected anatomy without duplicate architecture truths or unresolved gross packaging collisions.

Evidence: DIGITAL.

## Gate 5 — Full-face physical alpha

Pass when a safe prototype can execute one representative complete facial routine autonomously with rapid release, acceptable leakage/airway behavior and no manual finishing step.

Evidence: BENCH + HUMAN.

## Gate 6 — Human-factors quality

Pass when representative users can place, start, tolerate, remove and return the product successfully and the experience is compatible with the intended vision/use activities.

Evidence: HUMAN.

## Gate 7 — Premium physical quality

Pass when the primary control, retention/release, dock settlement, service cartridge, surface transitions, acoustics and CMF no longer feel prototype-grade.

Evidence: BENCH + HUMAN + supplier samples.

## Gate 8 — Hygiene / ownership proof

Pass when repeated real skincare use does not create unacceptable residue, odor, staining, wet cavities or service burden and the dock ownership loop works in realistic home use.

Evidence: BENCH + HUMAN.

## Gate 9 — Optical / thermal proof

Pass separately for each treatment capability only when the actual output, uniformity, safety, thermal behavior and claims territory are validated.

Evidence: BENCH + REG/CLAIM where needed.

## Gate 10 — Facial SPF proof

Pass only when final-film application and the intended sunscreen claim/use model satisfy appropriate evidence/regulatory requirements across representative faces/products.

Evidence: BENCH + HUMAN + REG/CLAIM.

## Gate 11 — Compatibility-scale proof

Pass when the product database/application system covers enough real target-market skincare to make “Masck adapts to your routine” credible rather than theoretical.

Evidence: data + BENCH + market/product study.

## Gate 12 — Demand/economics proof

Pass when target users understand Masck as an automated facial-skincare routine, want the experience at a viable price, and the resulting hardware/service economics support the product.

Evidence: HUMAN + commercial/supplier evidence.

## Gate 13 — Production-intent closure

Pass when material qualification, DFM, tolerance, reliability, compliance, serviceability and supplier evidence support the actual final product rather than a digitally idealized prototype.

Evidence: DIGITAL + BENCH + SUPPLIER + REG/CLAIM.

## Promotion rule

No gate may be claimed from a weaker evidence class merely because the result looks plausible. In particular:

- CAD is not comfort evidence;
- simulation is not skin evidence;
- dispensed volume is not sunscreen protection evidence;
- community usage is not formal validation;
- a render is not perceived-quality evidence;
- a green CI run is not proof of physical feel.
