# Digital product presentation

This directory contains the website presentation source and visual assets. Start with the [repository overview](../README.md) for the venture's stage and the [evidence guide](../docs/EVIDENCE_GUIDE.md) for technical substantiation.

`index.html`, `perfect-a.css`, `perfect-b.css`, `perfect-c.css` and `perfect.js` form the current page implementation. Images and supporting manifests retain their existing paths for asset provenance and compatibility.

Website visuals, interface concepts and product descriptions are not evidence of manufactured hardware, measured performance or live device telemetry. The [digital product handoff](../DIGITAL_PRODUCT_HANDOFF_README.md) defines the claim boundaries for presentation work.

Earlier construction and QA tooling is indexed in [.site-build/](../.site-build/README.md). Review workflow dependencies before moving assets or running historical scripts.
